Learn the Agent2Agent protocol,
without the overwhelm

The Agent2Agent (A2A) protocol is becoming the industry standard for how AI agents talk to each other. The official documentation at a2a-protocol.org is great and thorough — and a lot to take in when you are just starting out. This is the opposite: one server, one client, roughly 100 lines each, doing one full round trip so you can see what A2A actually is.

Get the code See the live AgentCard

Why this exists

Most A2A material starts with the full spec: transports, streaming, push notifications, task lifecycles. Useful later. Confusing on day one.

What you get here is the core of the A2A protocol:

Small enough to read

No framework layers, no orchestration, no LLM. Two files you can read top to bottom in a coffee break. This is the core of the A2A protocol.

Get results from A2A servers

You see both halves of a completed task in one reply: a human-readable status message, and structured data shipped as an artifact. This is an important learning: the results of an A2A server have to be in the artifacts, not in the status message.

Real protocol, not pseudo-code

Genuine AgentCard discovery, a real SendMessageRequest, a real completed task with an artifact.

One round trip, start to finish

That is the whole protocol surface this demo touches. Everything else in A2A is built on top of these three moments.

STEP 01

Discover

The client fetches the AgentCard and learns where and how to talk to this agent.

STEP 02

Send

The client sends a message to the server's interface, which it found in the AgentCard.

STEP 03

Receive

Back comes a completed task: a status message that thanks you, plus an artifact carrying structured JSON.

Try it

Two ways in. Local starts both sides. Live only needs the client — this site already is the server.

Local

Clone the repo. Start the server in one terminal, then talk to it with the client in another.

# terminal 1 — start the agent
uv run python A2A/server.py
Uvicorn running on http://localhost:8001
# terminal 2 — send a message
uv run python A2A/client.py Hi there
Thanks for your message: 'Hi there'. The result is in the artifact.

Live

This page is already served by the running agent. Clone the repo and run only the client, pointed at this origin.

A2A_URL=https://learn-a2a.com uv run python A2A/client.py Hi there
